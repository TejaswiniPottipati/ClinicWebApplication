# Deployment

```
Browser ──▶ web (Vercel) ──▶ api (Render) ──▶ Postgres (Neon)
                                  └──▶ Cloudflare TURN (optional)
```

Every push to `main` deploys:

1. **GitHub Actions** runs CI (lint, type checks, tests, migrations, builds).
2. **Render** deploys the API from `render.yaml` once CI passes. The build runs `prisma migrate deploy`; if a migration fails, the old version keeps running.
3. **Vercel** deploys the web app. Other branches get preview deployments.

The API runs on Render rather than Vercel because it keeps state in memory (live connections, call timers), which needs one always-running process. The web app has no such state, so it suits Vercel's serverless functions.

## One-time setup

**1. Database: [Neon](https://neon.tech) (free)**
- Create a project (Postgres 17, region near Render's, e.g. AWS US West 2 / Oregon).
- Copy the connection string with **pooling turned off** (no `-pooler` in the host).

**2. API: [Render](https://render.com) (free)**
- **New → Blueprint** → this repository (Render reads `render.yaml`).
- Set `DATABASE_URL` to the Neon string. TURN keys: both or neither. `JWT_SECRET` is generated.
- Check `https://<service>.onrender.com/health` returns `{"status":"ok"}`.
- Load the demo data once: `cd api && DATABASE_URL='<neon string>' npm run db:seed`.

**3. Web: [Vercel](https://vercel.com) (free Hobby plan)**
- **Add New → Project** → this repository, **Root Directory** `web`.
- Environment variables (Production and Preview):
  - `API_URL`: the Render URL, no trailing slash.
  - `SESSION_SECRET`: `openssl rand -base64 32`, marked Sensitive.

**4. GitHub:** add a ruleset for `main` that requires a pull request and the **API** and **Web** checks.

## Environment variables

| Variable | Where | Value |
| --- | --- | --- |
| `API_URL` | Vercel | Render URL of the API |
| `SESSION_SECRET` | Vercel | Random, different from local |
| `DATABASE_URL` | Render | Neon direct connection string |
| `JWT_SECRET` | Render | Generated by `render.yaml` |
| `CLOUDFLARE_TURN_KEY_ID`, `CLOUDFLARE_TURN_API_TOKEN` | Render | Optional |
| `STUN_URLS` | Render | Optional |

A changed variable applies on the next deploy (Vercel: **Redeploy**; Render: **Manual Deploy**).

## Things to know

- **Render free tier sleeps** after 15 idle minutes; the next request takes up to a minute. A free uptime monitor pinging `/health` every 10 minutes keeps it awake.
- **Vercel ends requests after 300 s** (Hobby). The live event stream reconnects automatically.
- **Rollback:** Vercel → Deployments → **Promote to Production** on an earlier one; Render → Events → **Rollback**. Applied migrations are not rolled back.
- **Demo only:** free tiers don't include HIPAA agreements. Don't store real patient data.
